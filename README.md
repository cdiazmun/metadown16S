# metadown16S (*work in progress*)
The typical workflow to deal with metabarcoding data (*e.g.,* 16S rRNA gene sequencing) and perform a series of common downstream analyses. 

The `README.md` file of each section will serve as a guide/tutorial. Please be aware that most of the scripts will need to be adapted to your files, path, and directory organization. The pipeline consists of the following steps:

1. Processing of fastq reads, ASV inference, and taxonomy assignment
2. Rarefaction analysis
3. Descriptive analysis
4. Alpha-diversity
5. Beta-diversity
6. Functional analysis
